## dnd-wordle-website-project
A Wordle like game that is DND themed with different game modes

## Current Plan
Title: D&Dle

First Game Type: Spellbook
Users will be given a spell description and have to determine the spell's name and the spell's level. If spell is lower then an arrow would point up to indicate that the spell is of a higher level and the inverse for if its a lower leveled spell. Spell Names will look for how similar the spell's function is to another. Firebolt and Fireball for example both have something to do with fire, so there will be a yellow similarity.
